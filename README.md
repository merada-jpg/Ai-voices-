# AI Voices

واجهة تجريبية لتحويل النص إلى كلام (TTS) تعمل مباشرة في المتصفح.

## ما تم إصلاحه
- استبدال README الافتراضي الناتج عن AI Studio بمنتج قابل للتشغيل.
- واجهة عربية RTL ومتجاوبة.
- اختيار الصوت والسرعة والحدة ومستوى الصوت.
- أزرار تشغيل/إيقاف مؤقت/إيقاف ومسح.
- تفضيل الأصوات العربية تلقائيًا عند توفرها.
- لا توجد مفاتيح API أو أسرار داخل المستودع.

## التشغيل
افتح `index.html` مباشرة أو استضف الملفات الثلاثة على GitHub Pages / Vercel / أي استضافة ثابتة.

## ملاحظة تقنية
هذه النسخة تستخدم Web Speech API في المتصفح. جودة وتوفر الأصوات يختلفان حسب نظام التشغيل والمتصفح. لإضافة أصوات AI حقيقية (مثل مزود TTS سحابي أو نموذج محلي) نحتاج طبقة Backend/API لاحقًا حتى لا تتسرب المفاتيح السرية إلى الواجهة.

## الخطوة التالية
إضافة Backend آمن، إدارة المستخدمين، حفظ المشاريع، تصدير MP3/WAV، ونظام اشتراكات عند تحويل المشروع إلى SaaS.
