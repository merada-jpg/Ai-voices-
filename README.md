# AI Voices

AI Voices هو مشروع لتحويل النص إلى كلام مع واجهة عربية RTL، نسخة ويب تعمل في المتصفح، ونسخة Android قابلة للبناء تلقائيًا عبر GitHub Actions.

## REDTEAM — ما كان ناقصًا

النسخة الأولى لم تكن منتجًا مكتملًا: كانت مجرد واجهة تجريبية تعتمد على Web Speech API، بدون محرك صوت AI سحابي، حسابات مستخدمين، تخزين مشاريع، تصدير MP3/WAV، أو Backend آمن.

وكان في نسخة Android عيب معماري مهم: الاعتماد الكامل على `speechSynthesis` داخل WebView قد يختلف أو يتعطل حسب إصدار WebView ومحرك الكلام في الهاتف.

## النسخة المصححة

- واجهة عربية RTL ومتجاوبة.
- اختيار الصوت والسرعة والحدة ومستوى الصوت في الويب.
- Web Speech API مع fallback مناسب للمتصفح.
- Android يستخدم `TextToSpeech` الأصلي بدل الاعتماد على WebView للصوت.
- النص والواجهة مضمّنان داخل APK؛ لا يحتاج التطبيق إلى موقع خارجي حتى يفتح.
- لا توجد مفاتيح API أو أسرار داخل المستودع.
- GitHub Actions يتحقق من بناء APK في Pull Requests.
- عند الدمج إلى `main`، يتم بناء APK ونشره تلقائيًا كـ GitHub Release.

## APK

كل إصدار ناجح على `main` ينتج APK تجريبيًا موقّعًا بتوقيع debug لأغراض التثبيت والاختبار.

هذا ليس بعدُ إصدار متجر Google Play Production؛ للإصدار النهائي سنضيف توقيع Release محفوظًا في GitHub Secrets، ثم AAB وPlay App Signing.

## التشغيل محليًا

### الويب

افتح `index.html` مباشرة أو استضف المشروع على GitHub Pages أو Vercel.

### Android

يتطلب Android SDK وJDK 17 وGradle 8.13. ويمكن أيضًا ترك GitHub Actions يبني الـAPK تلقائيًا.

## OODA — المسار التالي

1. Observe: اختبار APK على أجهزة Android حقيقية، خصوصًا العربية.
2. Orient: قياس جودة النطق، السرعة، الاستقرار، واستهلاك الذاكرة.
3. Decide: اختيار مزود TTS سحابي عالي الجودة + Backend آمن.
4. Act: إضافة حسابات، مشاريع محفوظة، تصدير MP3/WAV، مكتبة أصوات، نظام Credits وخطط، ثم إصدار Android Production.

## حدود النسخة الحالية

هذه ليست بعد منصة AI TTS SaaS كاملة. الصوت الحالي يعتمد على محرك الجهاز في Android أو Web Speech API في الويب. إضافة أصوات AI عالية الجودة تتطلب Backend ومزود TTS وإدارة أسرار وتكاليف.

لا نضع أي API key داخل الواجهة أو APK.
